# The Kiran Academy Website Clone

A responsive, single-file HTML recreation of the [The Kiran Academy](https://thekiranacademy.com/) homepage.

## Preview

Open `index.html` in any modern browser. No build tools or package installation are required.

## Included

- Responsive layouts for desktop and mobile
- Course overview cards and an expandable course menu
- Student placement cards, testimonials, hiring partners, branch information, and job openings
- FAQ accordion
- Demo request forms with local confirmation feedback
- Clickable phone and WhatsApp links

The demo forms only show an on-page confirmation. They do not send or store form submissions.

## Files

- `index.html` — complete website, including its styles and interactions

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and this `README.md` to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. After GitHub finishes publishing, the Pages address appears in the same settings section.

If you keep these files inside an `outputs` folder in the repository, move them to the repository root or configure Pages to publish from that folder using a deployment workflow.

## Notes

- The page uses Google Fonts when an internet connection is available; system fonts are used as fallbacks.
- Phone and WhatsApp links point to the contact details shown on the source website.
- This is an independently created front-end recreation, not the original site's source code or a connected lead-capture system.
