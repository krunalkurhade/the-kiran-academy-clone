# 🎓 The Kiran Academy Website Clone

A responsive front-end recreation of **The Kiran Academy** website, created for learning and practicing modern web development using HTML, CSS, and JavaScript.

> ⚠️ **Disclaimer:** This is an independently created educational project. It is not the official website or source code of The Kiran Academy.

---

## 🌐 Live Demo

🚀 **[View Live Website](https://tourmaline-palmier-cb5035.netlify.app/)**

## 📌 Project Overview

This project is a front-end recreation of The Kiran Academy website.

The goal of this project was to practice:

* Website layout design
* Responsive web development
* HTML5
* CSS3
* JavaScript
* Navigation and interactive components
* Git and GitHub
* Website deployment

* 📱 Responsive design for desktop, tablet, and mobile

## 🚀 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/krunalkurhade/the-kiran-academy-clone.git
```

### 2. Open the project

```bash
cd the-kiran-academy-clone
```

### 3. Run the website

Open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server**:

```text
Right Click → Open with Live Server
```
